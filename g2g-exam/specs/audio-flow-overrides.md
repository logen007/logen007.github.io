# Per-exam listening flow

Status: APPROVED — user request, 12 October 2026.

The listening skill settings allow an author to configure each part's playback
flow. This is an explicit per-exam override, not a change to provider defaults.

- Source: each question, each pair of questions, or one whole-part recording.
- Instruction, example and scored audio each repeat 1–3 times.
- Scored recordings repeat consecutively or as a complete round.
- Instructions precede examples, which precede scored recordings.
- Existing approved policies remain unchanged when no override is stored.
- Restore default removes only the override. Audio files are never deleted.
- Attempt snapshots retain their original configuration.
- The default-per-question-score input is removed from skill settings; existing
  question scores and saved scoring defaults remain unchanged.

The shared playback planner owns sequencing for runtime, preview and authoring
audio placement. A part still permits one listening session, with no pause or
manual replay. This request does not change question structure or grading.
